SEC 03
MEMO · 观影备忘

进场前后八件值得记下的事

这些备忘来自实际观影记录，不是为了周全，而是为了少踩几次同样的坑。

BEFORE SHOW · 进场前
  1. 确认场次编号同名影片常有多个场次，只记片名容易跑错厅，记下 MQ 编号更稳。
  2. 算好进场时间开场前十五分钟到比较合适，太早站着等，太晚容易错过前情。
  3. 问清时长超过两小时的片子，先想好散场后的安排，避免赶车。
  4. 提前查忌口同行的人若怕惊悚或哭戏，开场前说明比中途安慰有用。
AFTER SHOW · 散场后
  1. 先各自说一句散场后十分钟别急着看手机，各自说一个最记得的画面。
  2. 记下分歧点对同一场戏理解不同的人，往往聊得最久，值得记一笔。
  3. 补看前情发现漏了前作设定的，先补再看，顺序错了体验差很多。
  4. 更新场次备忘实际体验与场次备注不符的，及时反馈，下一期会修正。
SEC 04
TYPE · 场次分类

十二类场次，按影片类型与放映形式划分

分类只影响排片偏好，不影响场次编号。同一部片子可能同时出现在多个分类里。

TYPE 01

剧情长片

单次放映，时长多在九十到一百五十分钟，排片最密集。

TYPE 02

剧集连放

一次放两到四集，中间休息十分钟，适合追进度。

TYPE 03

短片热身

半小时以内，多作为长片前的开胃场。

TYPE 04

纪录片

节奏偏慢，建议预留完整时段，中途离场容易断线。

TYPE 05

动画专场

画幅与音效要求高，优先安排设备较新的厅。

TYPE 06

经典重映

老片加映，场次时间相对固定，多在周末下午。

TYPE 07

加映场

应需求临时加开，时间与厅号变动较频繁。

TYPE 08

映后交流

放映后留二十到四十分钟讨论，含映后场的会特别标注。

TYPE 09

合集连看

同一主题的片子连排，中间休息较长，适合整天安排。

TYPE 10

首轮放映

首次安排的场次，备注会写得比较详细。

TYPE 11

收尾篇

系列的最后一部分，建议先补完前作再看。

TYPE 12

备用场

场次时间未最终确认，标注为待核对，以最新更新为准。
